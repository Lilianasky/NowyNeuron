# NowyNeuron

Projekt edukacyjny o neuroplastyczności — jak przeprogramować mózg i budować trwałe nawyki.

## Co tu znajdziesz

- E-book: **21-dniowy plan neuroplastyczności**
- Materiały do prezentacji
- Szablony postów i awatary
- Strategie zmiany środowiska i nawyków

## Jak zacząć

Zacznij od e-booka w folderze `E-book/` — znajdziesz tam 21-dniowy plan działania gotowy do druku.
